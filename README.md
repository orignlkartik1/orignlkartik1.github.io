# Kartik Gupta — Portfolio

Personal portfolio hosted with GitHub Pages. The site uses a custom Cyber Emerald visual theme with responsive navigation, animated canvas effects, project filters, and an interactive terminal.

## Local preview
Open `index.html` in a browser. No build step is required.

## Update content
- `index.html`: portfolio content and project links
- `style.css`: visual styling
- `script.js`: navigation, typewriter, filters, canvas, and terminal interactions
- `resume.pdf` / `resume.md`: downloadable and Markdown resume

All skills and project descriptions should reflect demonstrable experience.
